# Step 42.04.1 — SF settlement departure hooks

**Repos:** `Workspace/simplefactions`  
**Depends on:** [04-sf-relocate](./04-sf-relocate.md)  
**Spec:** [Settlements.md](../../../../Workspace/simplefactions/Documentation/Settlements.md) — Guild departure

## Goal

Centralize city disband-when-empty on guild capital departure and guild removal, so evict, delete, and elevate are covered — not only explicit relocate paths.

## Build

| File | Change |
|------|--------|
| `settlement/handler/SettlementHandler.java` | `onGuildRelocateFrom` → `onGuildDepartedCapital`; `dissolve` uses `setCapital(-1, false)` |
| `Guild/Guild.java` | `setCapital(i, notifySettlement)` departure hook; remove redundant calls from relocate |
| `Objects/Handler/GuildHandler.java` | `onGuildDepartedCapital` on `removeGuild` when capital still set |
| `Managers/RelocationPrompt.java` | `setCapital(-1, false)` for temporary claim shim |

## Verify

| Check | Expected |
|-------|----------|
| Evict last guild in city | Settlement dissolved |
| Evict with other guilds remaining | City survives |
| Guild delete (capital still set) | Settlement dissolved if last occupant |
| Elevate sole city occupant | Old faction city dissolved |
| Cross-faction / intra-faction relocate | No regression; no double dissolve |
| Intra-faction relocate with claim shim | City not dissolved mid-claim |

**Done** (2026-08-15).
